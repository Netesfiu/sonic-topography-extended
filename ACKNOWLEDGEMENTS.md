# Acknowledgements

Sonic Topography Extended is built on the work of the original **Sonic Topography** project and the open-source libraries and platforms that make this visualization possible.

## Original project

**Sonic Topography / 音域回响** was originally created by **CmzYa**.

- Original repository: https://github.com/CmzYa/sonic-topography
- Original author: https://github.com/CmzYa

This repository is a modified and extended version of that project. It is not presented as an official release by the original author.

The original visual concept, terrain-based audio visualization, shader architecture, Wallpaper Engine integration, ripple/meteor effects, media controls, themes, and substantial portions of the underlying implementation originate from the upstream project.

## Extended version

The extended version is maintained by **Netesfiu**:

- Repository: https://github.com/Netesfiu/sonic-topography-extended
- Support: https://ko-fi.com/netesfiu

The extended work includes, among other changes, stereo-aware spectrum handling, enhanced onset and rhythm analysis, predictive beat tracking, frame-rate-independent audio smoothing, spectral memory, stereo spatialization, music-driven terrain coherence, resolution-aware music lamps, randomized lamp layouts, bass-core lamp exclusion, settings refinements, and Wallpaper Engine packaging/deployment improvements.

Support through Ko-fi is entirely optional and does not provide, remove, or restrict any rights granted under the GNU GPL.
